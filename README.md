# SpendWise — Smart Expense Tracker

A clean, hackathon-ready expense tracker web app for students and young professionals.

## Problem
Many students do not track small daily expenses, so they overspend without realizing it.

## Solution
SpendWise helps users add income and expenses, view total income/expense/balance, track monthly budget usage, and keep a simple transaction history.

## Features

- Add income and expense transactions
- Categorize spending: Food, Travel, Shopping, Education, Health, Salary, Other
- Monthly budget tracking with progress bar
- Auto-calculated income, expense, and balance
- Transaction history
- Sample data button for quick demo
- Local browser storage using `localStorage`
- Responsive design for mobile and desktop

## Tech Stack

- HTML
- CSS
- JavaScript
- LocalStorage

## How to Run

1. Download or clone this project.
2. Open `expense-tracker.html` in any browser.
3. Start adding transactions.

No installation is required.

## Demo Script

1. Open the app.
2. Click **Load Sample** to show example transactions.
3. Add a new expense like `Snacks - ₹100`.
4. Show how income, expense, balance, and budget bar update automatically.
5. Explain that data remains saved in the browser.

## Pitch

SpendWise solves the problem of unmanaged daily spending for students and young professionals. It provides a simple dashboard to track income, expenses, balance, and monthly budget usage. The project is lightweight, easy to use, and can be expanded with charts, cloud sync, and AI recommendations.
